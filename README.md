# Sistema de Gestión de Clínica Veterinaria

Aplicación web desarrollada con **Flask** y **SQL Server**.

## Instalación
1. Clonar el repositorio.
2. Instalar dependencias: `pip install -r requirements.txt` (si tienes este archivo).
3. Configurar la conexión a la base de datos en `app.py`.
4. Ejecutar el script de la base de datos ubicado en `database/clinica_db.sql` en tu servidor SQL Server.

## Tecnologías
- Python / Flask
- SQL Server
- Bootstrap 5
